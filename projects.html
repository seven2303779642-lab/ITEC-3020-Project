04 · Game interface modification

Public prototype

VectorPath HUD

A navigation aid for manual piloting in Space Engineers that turns live ship and route data into readable cockpit guidance without taking control away from the player.

Role
Creator, designer, and developer
Tools
C#, Space Engineers ModAPI, Rich HUD
Context
Client-side game modification
Status
Public prototype; private main build

Problem High-speed manual travel makes braking, alignment, and remaining-distance information difficult to judge.

Approach Combine a data-rich control panel with cockpit-relative pointers, alignment rails, and localized diagnostics.

Boundary The mod provides read-only guidance; it does not fly the ship, avoid obstacles, or guarantee a safe route.

The primary development repository remains private. A separate public prototype repository is available for review.
